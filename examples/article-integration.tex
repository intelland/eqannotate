\begin{annotatedequation}
\hat y=\eqmark[blue]{predictor}{f_\theta(x)}+\eqmark[orange]{residual}{r_\phi(x)}

The long annotation should wrap within the active text width and the following prose should start below the measured wrapped label. \demotext
